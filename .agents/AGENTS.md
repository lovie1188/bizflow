# Workspace Rules

## 1. Double Audit & Review Rule
- **Description:** जो भी काम (code change, feature addition, configuration update) किया जाए, कम से कम दो बार उसका initial audit और review करना अनिवार्य है।
- **Process:** 
  1. काम पूरा करने के बाद पहला audit करें (क्या सब सही जगह लगा है?)
  2. दूसरा review करें (क्या कोई edge case या error छूट गया है?)
  3. दोनों review पास होने के बाद ही confirm करें कि "सब सही से किया गया है"।
